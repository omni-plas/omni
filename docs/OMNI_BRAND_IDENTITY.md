# Omni Official Brand Identity

## Official logo

Omni's official logo is the selected three-dimensional winged lightning-and-infinity emblem.

The emblem combines a central lightning bolt, an integrated infinity symbol, and symmetrical wings. Together they represent power and speed, Omni's open-world nature, and freedom/extensibility across languages, targets, environments, and eras.

The official mark is Omni-native and must not contain unrelated religious, third-party, or external-language symbols as part of the core identity.

## Official source-file extension

The official source-file extension for the Omni programming language is `.oi`.

`.oi` identifies source code written in Omni, in the same identity relationship that `.py` has with Python.

Examples: `main.oi`, `app.oi`, `server.oi`, `game.oi`.

## File association

Omni tooling, editors, IDEs, file managers, installers, and operating-system integrations should associate `.oi` files with the Omni emblem. The full wordmark is intended for large branding surfaces; the emblem-only mark is preferred for `.oi` file icons, favicons, and compact application icons.

## Canonical asset

`assets/branding/omni-logo.jpg` is the canonical repository logo/icon reference. Platform-specific icon formats may be generated from it without changing Omni's underlying identity.
