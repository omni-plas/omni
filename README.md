# Omni

Official Omni identity: three-dimensional winged lightning-and-infinity emblem. Official Omni source extension: `.oi`.

Every `.oi` file created or registered through Omni uses the **canonical colored Omni logo** as its file icon. The cross-platform policy is defined in [`omni/oi_file_icon.py`](./omni/oi_file_icon.py). Omni platform installers convert the canonical colored asset to the native icon format required by the host OS (for example ICO on Windows, ICNS on macOS, and SVG/PNG on freedesktop/Linux) while preserving the same colored artwork.

Canonical branding documentation: [`docs/OMNI_BRAND_IDENTITY.md`](./docs/OMNI_BRAND_IDENTITY.md)
Canonical repository logo asset: [`assets/branding/omni-logo.jpg`](./assets/branding/omni-logo.jpg)
Packaged logo asset: [`omni/assets/branding/omni-logo.jpg`](./omni/assets/branding/omni-logo.jpg)

Omni is an independent, open-world digital creation, transformation, compilation, packaging, installation, execution, and maintenance engine. See [`SPEC.md`](./SPEC.md) for the full definition.
